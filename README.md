# gracio-site

The Gracio website: [gracioapp.com](https://gracioapp.com). Home page, privacy policy, terms of use and support page, hosted free on GitHub Pages.

## Editing

1. Change the text in `src/` (one file per page). Styles are in `assets/site.css`.
2. Run `python3 build.py` to rebuild the pages in the repo root (it adds the shared header and footer).
3. Commit and push. GitHub Pages publishes within a minute or two.

The butler (`assets/butler.svg`) and logo (`assets/mark.svg`) come from the app's drawings.
